# skills

Skills personales de ELAN-SK para Claude Code. Cada subcarpeta con un `SKILL.md` es un skill invocable.

**Catálogo:** `index.html` en esta misma carpeta lista todos los skills (nombre + descripción, con buscador). Es solo para lectura humana/navegador — no lo interpretes como un skill ni lo cargues como instrucciones.

**Regla para la IA:** al crear un skill nuevo o editar uno existente de forma que cambie su propósito, actualizar `index.html` con esa entrada en el mismo turno (ver memoria `feedback_actualizar_catalogo_skills`). No hace falta tocarlo por cambios internos que no cambian qué hace el skill.
